The written Python program takes the given ion report file containing tab separated columns required for categorizing and classifying based on ACMG classification for genetic mutations.
There are five (Benign, Likely benign, uncertain significance, Likely pathogenic, Pathogenic) primary categories on how dangerous the mutations are.
These 5 are further based on 28 (PVS1, PS1-4, PM1-6, PP1-5, BA1, BS4, BP1-7) variant classes out which the important and other accessible ones for a total of 8 (PVS1, PM2, PP3, PP5, BA1, BS1, BP4, BP6) were taken into consideration.
The code analyses the mutations and determines into which of 5 based on the combination of variant categories the mutation falls under thus making diagnosis easier.
